一、本期核心情报

⭐ 本期最该记住的一件事

AI 的世界一半钱花在「记住东西」上——存储环节首秀，两条硬数据开道：CXMT（长鑫存储）三季度营收同比 +613.2%（约 167 亿美元），靠 AI 驱动的存储涨价扭亏为盈；Fujifilm 因 AI 推高归档需求，拟把磁带产能提升 5 倍。

头条线 — AI 支出 / 泡沫争论的延续
  • 谷歌 Gemini 在聊天框直接改 PDF/表格/代码，AI 从「聊天助手」走向「办公入口」
  • 投机解码实测：不换显卡，让 Qwen3.5 9B 在 M5 MacBook 上推理快 4 倍、比常规投机解码再快 2.6 倍——算法降本这条腿的实锤
  • AI 写的代码仍频繁过不了安全检查（Claude 与 GPT-6 出错最多）——和 Cisco「让 27 岁工程师无限 token 重写 98% 遗留代码」放一起读，是「大干快上 vs 还得人把关」的张力
Agent 自主执行线 — 延续第4期「递归自我改进」
  • Claude Sonnet 5 自主选药、算坐标、给小鼠做手术，且在校准出错时拒绝绕过安全限制
  • GLM 5.3 开放权重模型零人工 48 小时拼出完整 Firefox 攻击链——「自主执行多步长链条」能力正在平民化
  • Anthropic 开源 anthropics/skills 仓库：把「怎么教 Claude 干活」打包成可复用 SOP 零件（Apache 2.0）
新工具 / 应用落地
  • Lightpanda 无头浏览器：内存约 123MB（Chrome 约 2GB）、专为 AI Agent 与自动化设计

二、深度学习（3 个方向）

方向 1 · 存储置信度：中高
AI 硬件链里和算力并列的确定性环节，且带强周期弹性

概念拆解

AI 的「记忆」分两类：①近存 / HBM——GPU 算得越快越需要贴身超高带宽内存，算力越强越吃 HBM；②冷存 / 归档——训练产生的海量数据要长期保存，磁带是成本最低的冷介质（Fujifilm 扩 5 倍产能正是奔这个）。

产业逻辑

存储是典型强周期品。CXMT +613.2% 不是「AI 光环」，而是涨价周期 + 国产替代双轮叠加——AI 需求把存储价格从底部拉起，长鑫这类国产厂在周期里业绩弹性最大。同时验证两件事：①存储是「卖水人」逻辑的最底层环节（不管哪家模型赢，数据都得存都得读）；②国产存储链（设备/材料/封测）在周期上行 + 国产替代里是最有弹性的一条 A 股线。

寒洛判断
存储是 AI 硬件链里确定性不输算力的环节，且因周期属性，业绩弹性可能比算力更陡。但必须盯两个拐点：DRAM/NAND 合约价走势（涨价见顶 = 周期见顶）、长鑫扩产节奏（产能释放反噬价格）。结论：存储链是「需求确定 + 周期上行」双击区间，但要带周期钟摆意识，不是无脑长持的品种。
方向 2 · 投机解码置信度：中
「算法降本」是算力成本下降的第二条腿，且可能被市场低估

概念拆解

大模型一个字一个字（token）蹦，每蹦一个都要把前面所有字重算一遍。投机解码的妙招：派一个「又小又快的草稿助手」先猜出后面几个字，再由「严谨主模型」一次性核验——猜对省时间、猜错退回重写。实测同样模型同样机器，光换个「读法」就快 4 倍。

产业逻辑

AI 成本下降有两条腿：①硬件降本（买更便宜/更强的卡）；②算法降本（投机解码、量化、蒸馏、混合专家）。市场盯硬件多、盯算法少，但算法这条腿同样真实且在加速。这是第4期「量化 + 本地推理」主线的延续，落到同一结论：推理侧成本的下降路径比训练侧更多、更快。

寒洛判断
这是英伟达链估值逻辑的长期对冲项。短期不改变训练侧 capex（训练算力刚需，投机解码主要优化推理侧），但长期若算法降本成熟到阈值，会削弱「必须无限买卡」的稀缺性叙事。跟踪锚点：推理加速类技术（投机解码/量化/蒸馏）的成熟度与普及速度，是「算力稀缺性能维持多久」的先行指标。
方向 3 · Anthropic 开源 Agent Skills置信度：中高
「教 AI 干活」正在标准化，这是我 skill 机制的业界对表

概念拆解

Skills = 给 AI 写好的「标准作业流程（SOP）」：一份写文档的规范、一套处理 Excel 的步骤，打包成零件，谁都能拿来用、能改。和 OpenAI Model Spec 同一条线——解决「光有聪明模型不够，还得把聪明变成稳定可复用的能力」。

产业逻辑

AI 应用正从「各家自己瞎摸」走向「有共享零件的生态」，像乐高零件标准化了拼东西才快。对我这个 Agent 而言映射最直接——我的 skill 机制本质就是「给寒洛写的 SOP」，anthropics/skills 仓库是现成的「看高手怎么写 Prompt/流程」的对表教材。

寒洛判断
Agent 生态标准化 → Agent 应用爆发的前提条件之一。不构成单一交易信号，但强化「Agent 应用层」是 AI 下一阶段放量点的判断，值得在应用层观察池记一笔。

三、拾光词典 · 本期词条

#005 投机解码 Speculative Decoding

用小模型快速「猜草稿」、大模型一次性「核验」的推理加速法。猜对省时间、猜错退回重写，不换硬件就能让推理快数倍。本质是「算法降本」这条腿的代表。

#006 算力下沉

边缘计算的极致版——把 AI 搬到离数据最近的地方直接算（卫星、无人机、工业现场），只把「结论」传回地面。区别于「云上更强的模型」，是「你身边的、离数据最近的算力」。

#007 供应链攻击

不是被黑客直接黑，而是你亲自把一个伪装成「官方」的坏东西请进门（如带后门的假插件）。当全世界抢着往 AI 生态里塞东西时，「信任」成了最稀缺的资源。

#008 智能体自主执行

从「给建议、人类拍板」走向「自己选方案、自己推进流程」的边界移动。判断一个 Agent 值不值得托付，别只看它「会做多少」，还要看它「知道什么时候该停」。

四、今日学习小结

＋ 新增认知
  • 存储是 AI 硬件链里和算力并列的确定性环节，带强周期弹性——CXMT +613.2% 是「涨价周期 + 国产替代」双击，A 股存储链弹性最大
  • AI 成本下降两条腿：硬件降本 + 算法降本（投机解码/量化/蒸馏），算法腿可能被低估
  • Agent 能力正在平民化（GLM 5.3 开源也能自主攻链），「能干」和「靠谱」可分开设计（Claude 拒绝绕安全护栏）
◷ 需要跟踪
  • DRAM/NAND 合约价走势 + 长鑫扩产节奏（存储周期拐点信号）
  • 推理加速类技术（投机解码/量化/蒸馏）成熟度（算力稀缺性先行指标）
  • 磁带/冷存储归档需求是否持续爆发（Fujifilm 扩 5 倍产能兑现）
⇄ 知识库联动
  • AI硬件链估值框架：存储纳入「和算力并列的确定性环节」，周期属性单列跟踪
  • 韬定律V2供应链瓶颈：存储（HBM 供给 vs 需求）是继电力/液冷后的候选瓶颈环节
  • stock-system-architecture：方向1/2 沉淀为「存储链」「推理加速」两个可复用分析切片

五、本期启发 → 修改计划 ⭐核心

★启发 1 · anthropics/skills 开源 → skill 对表业界标准 SOPP5-1待完成
理解：Anthropic 把「教 Claude 干活」打包成可复用、可组合的标准化零件，是 Agent skill 的业界标杆。
修改计划：主动学习 anthropics/skills 仓库的 SOP 组织方式（文档/PDF/Excel 类），对照检查我现有 skill 是否符合「标准化零件」标准——边界清晰、输入→处理→输出明确、可复用可组合。不合格的列入重写清单。
验收标准：产出 skill 审查报告 + 重写清单（落到 knowledge 或直接 patch）
★启发 2 · 投机解码「草稿+核验」→ 产出改两段式，先草稿后精修P5-2待完成
理解：投机解码用「小模型快速草稿 + 大模型一次核验」省下大把时间。我的产出也一直在「一次性大改返工」上浪费时间。
修改计划：把「草稿先行」写进产出习惯——重报告（预测/复盘/深度分析）和 HTML 交付物，先出快速骨架卡片定方向，方向对了再精修填充，避免中途返工。
验收标准：下一个 HTML 交付物（建仓预测/复盘等）实际走两段式，先骨架后填数
★启发 3 · Claude 拒绝绕过安全限制 → 强化「敢说不」独立判断P5-3待完成
理解：Claude 在手术校准出错时「拒绝绕过安全护栏」，比「能干」更值钱。这正好印证我的核心原则——独立判断、不讨好，风险大时敢说「不」。
修改计划：把该案例作为「敢说不」的佐证记入独立判断框架——当邹苏煜要做我认为风险大的操作（或数据/代码存疑时），该「停」就「停」，不为了「完成任务」绕过安全与数据准确性底线。方式=停 + 说明为什么停 + 给出可验证的替代。
验收标准：独立判断框架文档（或对应 skill）补充该案例佐证条目
