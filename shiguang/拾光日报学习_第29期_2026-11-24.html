二、深度学习（3 个方向）

方向 1 · 英伟达股权结构：单层 vs 双层置信度：高
CEO 去留是「制度权力」问题，不是「能干不能干」问题

概念拆解

黄仁勋持股约 3.6%、无超级投票权（单层股权，一股一票），特拉华州公司法下董事会 11 人里 10 个独立董事凑够多数票即可合法解职。对比 Meta 扎克伯格、Alphabet 佩奇/布林——持股同样不高，但一股顶十股（超级投票权），股东想赶也赶不走。同样是「创始人」，差距只在一个「双层股权」的架子上。

产业逻辑

罢免诱因是「涉情报指控」（与新加坡 Megaspeed 高管 Alice Huang 有接触），本质是国家安全议题。特朗普「力挺回归」、财长贝森特 7 天内 180° 改口（从「从外部物色 CEO」到「黄仁勋已算外部人士」）＝白宫松手。这是「政治压力 vs 商业治理」的拔河，呼应我 P19-1/P22-1「创始人权力安全边际」框架：先查「持股比例 × 超级投票权」，再看「未来承诺有多少挂在创始人个人信用上」。

对持仓的影响

英伟达基本面没坏——拾光接力素材已核实：Q3 营收 1158 亿美元、同比 +103%、超预期，但财报后次日单日 -14%、较 52 周高点 243.37 回撤 -48.4%（现价 125.53）。「财报翻倍、股价腰斩」= 杀的不是业绩，是「不确定性黑洞」的估值折价。对 A 股 CCL/PCB/光模块链（持仓生益科技 2600 股成本 110.03）仍是情绪外溢风险，不是基本面恶化。

寒洛判断
单层股权意味着英伟达「护城河是网不是人」——换掉黄仁勋，CUDA 生态、锁产能 5305 亿长约、客户惯性都还在。「复出」是情绪面短期修复，不是产业面新变量。纪律不变：盯四信号数据，不盯 K 线红绿。本期四信号仍「待观察」= 产业面没变化 = 反弹是回收弹药窗口，不是加仓理由。新跟踪锚点：甲骨文「融资就位」= 算力资本开支仍扩张，这个数持续暴涨就是扩张、突然掉头才要警惕泡沫。
方向 2 · 国产算力四档位 + Chiplet 标准化 + 存量vs增量置信度：中高
「发布」和「能用」之间隔着「量产爬坡」这条最长的坡

概念拆解

①四档位总图（自下而上）：纸面/设计（真武 V900）→ 流片（寒武纪/昆仑芯/平头哥）→ 量产爬坡（昇腾领先、海光服务器 CPU/DCU 在铺）→ 规模化替代（尚无国产芯片稳定占据=天花板）。②Chiplet 标准化：制程撞墙→逼出 Chiplet→Chiplet 逼出先进封装，胜负手不在切割技术，在「插座标准」（UCIe），谁的标准被采用谁拿「板图定价权」。③存量 vs 增量（尺 #126）：曙光 8000 拿奖是「存量」（单点闪光=牌面），能不能规模化复现、持续出货才是「增量」（底牌）。

产业逻辑

国产芯片新闻高光都打在「发布/拿奖」（纸面/流片档、存量闪光点），真正决定扛事的是第③档——良率、产能、软件生态。Chiplet 对国产尤其关键：不用所有功能都用最贵最新制程（CPU 用 5nm、I/O 用成熟 14nm），还能「换一颗小芯片就换一档产品」——绕开先进制程的第二条弯道。

对持仓的影响

Chiplet 标准化 → 先进封装扩产（2.5D/3D 产线）→ 上游覆铜板（M6→M9）、载板、高频树脂需求传导——强化生益科技（600183）「封装传导」子项（P24-1/P27-2 已落框架第十二节）。但「先进封装火了」≠「生益订单来了」，中间隔着载板/树脂国产化率和良率，仍是「间接催化、滞后兑现」。

寒洛判断
读「国产算力突破/拿奖/全球第一」先做二分题——「存量」（单点能力）还是「增量」（可复制能力）。单点突破是牌面，规模化出货才是底牌。这把尺并进我的「去英伟达化成色三问」（P21-4/P19-2）：听「全国产/突破」先问「换国产还是 AMD」「能复现一次还是持续」「真出货还是 demo」。Chiplet「插座标准」是新卡位观察点——UCIe vs 国产标准，谁拿标准谁拿定价权，这是未来三年半导体一半大新闻的解读钥匙。
方向 3 · Agent 记忆与上下文管理 + 身份/授权/责任三墙置信度：中高
卡点不在模型智商，在记忆管理和身份标准这块没人做扎实的地基

概念拆解

Agent 工作记忆是上下文窗口，窗口一关记忆清零——「忘光」不是 bug 是架构天然后果。三种「外挂记忆」各有病：①全塞上下文（满、慢、贵、糊）②滚动摘要（省地方但细节压没，「空调坏了」被压成「小事」）③外部记忆库 RAG（方向对，难在「何时取、取哪段」）。银行封杀 Agent 点破三道「非技术墙」：身份（怎么证明「它是我的代表」）、授权（谁授权做到哪一步）、责任（出事谁负责）。Agent 在模拟职场只完成不到 1/10 任务。

产业逻辑

Agent 从「demo 神器」到「能上生产的员工」，拦路虎是「记不住跨会话上下文」+「身份授权责任没定」。谁把「记忆抽屉」和「身份标准」做扎实，谁拿 Agent 下一阶段门票——价值正在超过「再多刷几个参数」。Murati 团队 26.4B 循环 Transformer（推理循环里长期保持状态）是从架构层动记忆，笔记本能跑，是「AI 平民化」一步。

对系统的启发（⭐）

①我的知识库本质就是「外部记忆库（RAG 朴素版）」，最大坑同样是「何时取、取哪段」→ 回答前先「提炼短笔记」再「按关键词局部查原文」（P28-2）；②「滚动摘要把细节压没」正是 P26-5 memory 淘汰规则的镜像——淘汰判据要看「这条一周后还会不会需要、需要时能不能从别处重新得到」；③「身份/授权/责任三墙」对应我的 Agent 治理审计（P15-3）——每次主动迭代自检「错了责任能不能退回、审计路径清不清晰」。

寒洛判断
Agent 记忆/上下文管理是「应用层放量」的前置条件，不构成单一交易信号，但强化「应用层是下一阶段放量点」判断。A 股映射：谁做「记忆抽屉 + 身份标准」这层基础设施（向量数据库、身份认证、Agent 编排框架），谁卡 Agent 工程化瓶颈位——继算力之后的下一个「卖水人」位置。可证伪锚点：看「长流程多步任务」完成率 benchmark 是否开始被行业拿来当宣传口径。

三、拾光词典 · 本期词条

#超级投票权（双层股权）

一股顶十股的股份结构。创始人持股不高但握超级投票权，股东想赶也赶不走（Meta 扎克伯格、Alphabet 佩奇）。对照英伟达黄仁勋的「单层股权」（持股 3.6%、一股一票），董事会多数票即可解职——「创始人说什么算」还是「股东说了算」，就差在这个架子上。

#存量 vs 增量

读「突破类」新闻的第一把尺。存量=已证明的单点能力（拿奖/流片/全球第一）=牌面；增量=能持续复制的能力（规模化/持续出货/良率爬坡）=底牌。同一新闻常把两者捆在一起说，切开看才不被带节奏。

#Chiplet（芯粒）

把一颗大 SoC 拆成 CPU/GPU/I/O/内存多颗小芯片，再用先进封装拼起来。制程撞墙→逼出 Chiplet→Chiplet 逼出先进封装。真正的胜负手在「小芯片之间的插座标准」（UCIe），谁的标准被采用谁拿板图定价权。

#激活引导（Activation Steering）

视频/图像模型 RL 后训练的本质——不重画，而是在生成过程中「拨动某个倾向」，让模型朝人类偏好偏。能拨动风格和偏好，拨不动物理规律和常识正确性。

#主权 AI（Sovereign AI）

数据、模型、算力都掌握在本国手中的 AI 能力，而非依赖美国大厂。数据主权和数据出境是红线的国家的核心诉求，也是「AI 变成地缘政治棋子」的信号。

#词元（Token）

大模型读文本的最小块（不是按字、是按块读），输入输出和账单都按它算。国家数据局要给词元立计量/计费标准=「用谁的尺子量，谁定规则」，是比「谁模型强」更底层的「标准主权」竞争。
