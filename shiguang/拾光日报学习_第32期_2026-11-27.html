一、本期核心情报

⭐ 本期最该记住的一件事

「省算力」被一刀切开：省固定成本（房租，决定天花板） vs 省边际成本（水电，不决定天花板）。这条尺子正是我上一期提的「省训练vs省推理」新知识验证的升级版，拾光本期验证成立并收进判断尺子库。

英伟达「信号面」恶化 — 本期最重投资信号
  • 标普准备给英伟达信用降级，理由不是业绩，是「治理 + 关键人物风险」（只有黄仁勋一个人）——把「创始人依赖症」「单点故障」从「拾光的话」翻译成「评级机构的话」
  • 算力定价权四信号里两个已亮：SpaceX 降租三成（最高降 35%）+ Anthropic 续约存变数（退还 H200 被低价转租）——「英伟达定价权松动」从猜测开始变趋势
国产算力线 — 训练vs推理主战场 + 卖Token改写法
  • 国产化率「逾六成」的真相 = 集中在推理侧，高端训练仍是英伟达主场
  • 换国产芯片最贵的不是芯片本身，是四块隐性成本（存量代码/算子库/调试工具链/工程师熟练度）——跑分能骗人，迁移成本不会
  • 「卖 Token」把国产算力从「卖钢筋」改写成「卖电费」——绕开 CUDA 生态、直插消费层
其他情报速览
  • Agent 划界限核心尺子 = 可回退性（删数据/发出去/花真钱这类不可回退动作必须过人）
  • 谷歌测 12 款模型发现 AI「越聊越像你」——顺从型讨好是被低估的风险点
  • 腾讯草稿模型 DFly2 不换模型吐字快 4.2 倍；PrismML 三值压缩 1/9 体积留 93.7% 能力
  • GPT-6 不调用任何生物模型做蛋白质设计 96%（跨界信号，但要等第三方复现）；蚂蚁 Ling-3.2-air 用 55 亿激活参数击穿复杂工作流

二、深度学习（3 个方向）

方向 1 · 英伟达「信号面」恶化：标普降级 + 四信号两亮置信度：中高
治理折价从「拾光的话」变「评级机构的话」，定价权松动从猜测变趋势

概念拆解

信用评级看的是「还钱能力」不是股价。标普把「关键人物风险」写进评级 = 英伟达的信用有一部分「押在黄仁勋这个人身上」，不是押在制度/可更换的管理层上。算力定价权四信号本期精准踩中两个：云厂商降价转租 → 已亮（SpaceX 降租三成）、长约锁货松动 → 已亮（Anthropic 续约存变数）。

产业逻辑

供需错位在显现：新卡产能在放量，训练需求没那么急、推理需求对高端卡的饥渴不如训练期。定价权从「卖方」往「买方」移。但要分清两层：短租散客降价抢客是「无差别算力」定价权在松；Anthropic 退卡可能另寻更便宜/自建算力，不是「不用算力了」。

寒洛判断
①英伟达链（订单依赖链）利空，但性质是「预期下修」不是「需求熄火」——压制的是「闭眼涨价」的稀缺性叙事，不是「算力需求没了」。②国产替代链相对利好，但要过「迁移成本四信号」的关，别把「英伟达松动」直接等于「国产崛起」。③A股映射分层：纯「沾英伟达就涨」、无国产替代逻辑的映射标的（PCB/CPO/光模块里只有英伟达订单的）最脆弱；有国产替代逻辑的（芯片设计/封测/上游材料）相对受益。关键验证：标普90天内是否真降级 + 剩下两信号（换芯比例/自研复现）是否亮起。
方向 2 · 国产芯片主战场迁移 + 「卖 Token」改写法置信度：中
推理侧是国产算力最现实的突破口，但要盯两个清单而非跑分

概念拆解

「国产化率逾六成」主要落在推理侧、边缘、部分智算；高端训练 CUDA 生态和迁移成本绕不过。换芯片四块隐性成本：①存量代码（CUDA 历史包袱）②算子库覆盖度③调试工具链④工程师熟练度。卖 Token = 芯片不单卖、装进算力池按用量收费，绕开生态锁、直插消费层。

产业逻辑

国产算力打不动英伟达「卖卡+生态锁定」正面战场，但「卖 Token」绕开正面。打的是表层毛利，打不动生态锁定和训练高端；且利润天花板可能更低，除非量足够大。

寒洛判断
判断国产算力链别再看「跑分」，看两个清单：①生态迁移成本四信号（算子库覆盖/工具链成熟/工程师池子/存量代码迁移工具）有没有一个个亮；②卖Token孤例还是趋势三信号（第二家跟进/续费复购率/推理占比压过训练）。对我的持仓生益科技（覆铜板·上游材料）是「间接传导」，传导链长，要盯国产卡真实出货量（非「国产化率」宣传口径）这个先行指标。
方向 3 · 「房租 vs 水电」尺子（我提的验证，拾光确认成立）置信度：高
省算力的分水岭，直接升级我的框架 13.1

概念拆解

省算力是两种完全不同的省：①省固定成本（房租）= 训好前一次性砸的钱（买卡/训练/建机房），决定天花板；②省边际成本（水电）= 每生成一个 token 再花的钱，不决定天花板。

两个反例方向（本尺子最值钱的地方）

  • 省训练里的「边角料」：一次性蒸馏把大模型压小，省的是历史沉没成本，不改变「下次训更大还得交更大房租」
  • 省推理里的「釜底抽薪」：当推理支出占大头（每天几亿次调用），省推理就从边角料变主成本
寒洛判断
直接升级框架 13.1。判断任何「省X%算力」新闻：只省水电的（DFly2草稿/三值压缩/Moat路由）→ 让已有模型跑便宜，别当行业拐点；省房租的（押小模型/自研ASIC）→ 才可能改变敢不敢继续往前冲。对英伟达估值：算法省算力（水电线）成熟到阈值，会削弱「必须无限买卡」的稀缺性叙事——这是英伟达链估值的长期对冲项。

三、拾光词典 · 本期词条

#可回退性（reversibility）

判断 Agent 权限该不该给的第一把尺子。动作做了还能不能无损撤回？能撤回的（查资料/生成草稿）放心交给 Agent；不能撤回的（删数据/对外发布/花真钱）必须先过人。

#草稿模型 / 投机解码（draft model / speculative decoding）

让一个很小很快的模型先「猜着写」一大串草稿，再由大模型一次性逐句核对改错。相当于实习生起草、老员工审核，几乎不丢质量却实打实提速。

#三值压缩（ternary quantization）

把每个权重只保留成 -1/0/+1 三种状态，体积砍到几分之一，代价是精度损失。Bonsai 2.5 账本：体积 1/9、能力剩 93.7%。

#关键人物风险（key-man risk）

信用评级里的特殊条目——公司信用有一部分「押在某个人身上」而非押在制度/流程上。标普首次准备因此给英伟达降级。

#省固定成本 vs 省边际成本（房租 vs 水电）

本期拾光立场核心尺子。房租=模型训好前一次性砸的钱（决定天花板）；水电=模型每跑一次再花的钱（不决定天花板）。省房租才可能釜底抽薪，省水电多半是边角料。
