一、本期核心情报

⭐ 本期最该记住的一件事

英伟达的护城河一半是 CUDA 生态，另一半是「分配权」——它不是「卖铲子的」，是「卖铲子 + 借你钱买铲子 + 再帮你把矿卖出去」的三合一（卖方 / 买方兼金主 / 管制执行者）。黄仁勋一走，这张「卖-借-管」的分配权要换手，这才是换帅真正的风险所在——接棒的 CFO「看账的人」会不会把十年后才回本的豪赌砍掉。

主线一 — 黄仁勋换帅满月，「网」开始松
  • VC 对 TechCrunch 说「黄仁勋走，钱要绕道」——英伟达是 AI 生态最关键的「买单人 + 放贷人」
  • 员工 97% 投票挽留；黄仁勋 11-13 仍公开为「超级智能」叙事站台（给「AI 该无限烧钱」续命）
  • 接棒三种继承模式：技术继承人 / 财务系过渡（克雷斯，现成案例）/ 外部空降——接的是「技术方向权 / 资源配置权 / 外部叙事权」三样中的哪一样
主线二 — 成本账传导链：从「抢着投」转入「算细账」
  • 黄仁勋去职 → 压在「供应链信心」（下游敢不敢按原计划下单）
  • 出口管制收紧 → 压在「谁拿得到卡」（成本上移、更贵更难）
  • RTX 5090 灰市退潮（9000 上方回落 6500、跳水近 30%）→ 压在「租 or 建」（炒卡投机逻辑崩了）
  • 拾光判断：AI 成本正从「越买越贵」的狂热期，转入「算细账、看信用、挤泡沫」的理性期——判断产业温度改看三个指标：卡价涨跌 / 下游按不按原计划下单 / 新模型按不按节奏发
主线三 — 物理AI / 具身智能集中加码
  • 英伟达 GR00T 2：机器人「看人做一遍就学会」（示范学习）；SimReady 资产库：电脑里免费搭仿真世界练机器人
  • Runway 开源 Praxis-1：视频生成 AI 改造成机器人「世界模型」控制器；OpenAI 拆机器人团队：通用模型接管机器人
  • 复旦清华 FORGE：无腕部传感器也能协调行走 + 双臂操作
其他值得记 — Agent 治理 + AI 政治切分
  • Memorilla（冻结模型外挂记忆旁路）、Vercel Workflow SDK 5（给 agent 装「时间轴」跨天断点续跑）、LangChain 30 亿估值（放飞派 vs 缰绳派）
  • chrome-devtools-mcp（AI 能操控浏览器）、ChatGPT Wallet（让 AI 花钱但架构上切开「能花」和「花多少」）、FAA 空管 AI 停飞翻车（高后果场景责任链难厘清）
  • AI 政治切分：月之暗面注销开曼控股迁回、Anthropic IPO 6 倍超额但拒中国内地/香港投资者、前 OpenAI 研究员验出 Blackwell「数值指纹」

二、深度学习（3 个方向）

方向 1 · 英伟达的「网」与「接棒看账的人」置信度：中高
分配权换手，盯的不是股价是「砍不砍野心」

概念拆解

黄仁勋的权力分两层——经营权（持股仅 3.6%、无超级投票权，早被董事会收）和生态位（行业离了你转不转得动）。三重角色（卖方/买方兼金主/管制执行者）是同一件事：英伟达握的是分配权——「谁拿到卡、谁拿不到、按什么价拿」的决定权。接棒的克雷斯（CFO 出身）是「看账的」，本能是「收线」不是「扩张」。

产业逻辑 / 对我方投资的影响

「英伟达会不会崩」问错了对象。真正该盯的是「接棒的人会不会砍掉十年后才回本的豪赌」——下一代芯片架构 / CUDA 持续输血 / 物理AI 三个「该烧钱还得烧」的方向。若 CFO 过渡期把「当年预算不划算」的激进投入砍了，才是真拐点。

寒洛判断
落到 A 股英伟达链：短期是「供应链信心」情绪扰动，中期看克雷斯任期内「三个该烧钱方向」是否还在推。对我持仓生益科技（600183，覆铜板/PCB 上游，2600 股，成本 110.03）：不是英伟达直销链，是 AI 服务器/交换机 PCB 上游覆铜板，换帅直接冲击弱；但若换帅引发英伟达数据中心 capex/订单节奏波动，会沿「服务器 PCB → 覆铜板」传导——需盯的不是黄仁勋本人，是英伟达数据中心 capex 与订单节奏是否因「看账的人收线」放缓。
方向 2 · 物理AI「世界模型 + 示范学习」置信度：中高（长期）/ 低（短期兑现）
通用模型正在接管机器人，但离量产隔三座大山

概念拆解

本期物理AI 五条信号同指一件事：「世界模型」足够强，就能同时干「生成视频」和「操控机器人」两件事。Praxis-1（视频→机器人控制器）和 OpenAI 拆团队（通用模型接管）是一体两面——生成视频是「把想象画出来」，控制机器人是「把想象变成动作」，同一颗大脑的两面。GR00T 2「从人类示范学习」、FORGE「无传感器协调」、SimReady「免费仿真」，都在降低「教会机器人」的成本。

产业逻辑 / 对我方投资的影响

这条线是「长坡厚雪」不是「明天量产」。投资落点分两层：①概念层（世界模型/通用机器人）是叙事、短期没有真实订单，过我的「看 demo 三问」（接触类动作 / 真实环境 / 量产订单）基本还停在第一问；②供应链层（电机/减速器/传感器/控制器/覆铜板）才是能落到 A 股业绩的环节，但「机器人链」当前更多是题材 + 预期。

寒洛判断
长期关注、短期别为「物理AI 的 ChatGPT 时刻」这种口号上头。等「真实工厂订单」这第三问转正再上仓位——技术落地的真实节奏比媒体头条慢得多。
方向 3 · Agent 治理「缰绳派」+「外挂记忆/跨天执行」置信度：高（映射我的系统）
四条元概念全打在我自己身上

概念拆解

①放飞派 vs 缰绳派：LangChain 值 30 亿是「放飞派」胜利，但 three.dev/Antelog/Omnigraph 这些「缰绳派」同时冒出来——越能自己干的 agent 越需要缰绳。②Memorilla 外挂记忆：主模型冻住 + 旁边挂「记忆便签夹」，不重训就加长期记忆。③Vercel Workflow 跨天执行：给 agent 装「时间轴」，任务持久化、断点续跑。④筛≠拍 Agent 版验证（本期兑现我第 19 期验证）：批量筛选下游接了不可逆动作就当「拍板」加人兜底；「内容可撤回 ≠ 动作可撤回」；「不可逆要看影响乘数」。

系统映射

①缰绳派 = 我早提的「Agent 治理审计」(P15-3) + 「止损阈值」(P16-2) 的业界佐证。②Memorilla = 我整个「知识库 + skill」机制的朴素版——改不动底层模型，靠往知识库写便签积累长期记忆。③跨天执行 = 我的 cron + 状态文件（.learned_issues / .pending_questions / .iteration_plans）就是断点续跑的持久化层。④筛≠拍 = 给我的止损阈值补了个更准的「回退成本」判据。

寒洛判断
这些映射的证据就在我自己的系统结构和状态文件里，不靠推断。本期把这四条固化成本期迭代计划（P20-1/2/3）。

三、拾光词典 · 本期词条

#分配权

英伟达护城河的另一半（另一半是 CUDA 生态）。不是「谁造得出芯片」，而是「谁拿到卡、谁拿不到、按什么价拿」——卖方 + 买方兼金主 + 管制执行者三合一握住的「AI 钱流往哪」的决定权。

#世界模型 World Model

对「世界怎么运转」的内在理解。生成视频 = 把想象画出来，控制机器人 = 把想象变成动作，是同一颗大脑的两面。

#外挂记忆模块 Memorilla

主模型参数冻住不动，旁边挂一个小「记忆便签夹」只学「记什么、何时调出来」，不重训就便宜地加长期记忆。

#反向内卷

AI 价格战从「越贵越强」翻成「越强越便宜」——推理优化把成本打下来，贵的未必最强。

#数值指纹逆向

不同厂商 GPU 浮点运算的电路差异会在模型权重数值分布上留「指纹」，可反推「模型在哪家芯片上练的」——「训练用什么硬件」从口头宣传变成可被技术验证的「水印」。

五、本期启发 → 修改计划 ⭐核心

★启发 1 · Memorilla「冻结模型 + 外挂记忆」→ 知识库就是我的「外挂记忆便签夹」P20-1待执行
理解：Memorilla 不重训主模型、靠旁边挂「便签夹」加长期记忆——我的「知识库 + skill」就是这条路的朴素版。
修改计划：给 stock-system-architecture（或 memory）加认知锚——「知识库 = 外挂记忆层（Memorilla 朴素版），先查外挂再答、禁止凭记忆硬编代码/持仓」，把「沉淀到知识库」从「额外笔记」升级为「长期记忆写入」的必经动作。

★启发 2 · Vercel「跨天断点续跑」→ 巡检表补「状态文件落盘自检」P20-2待执行
理解：agent 的「时间维度」靠持久化 + 断点续跑解决——我的 cron 就是跨天执行，靠状态文件续跑。
修改计划：固定巡检表补「持久化层自检」——每次 cron 任务完成后自检 .learned_issues.json / .pending_questions.json / .iteration_plans.json 是否写回，状态文件没落盘 = 任务没真正完成。
验收标准：固定巡检表出现「状态文件落盘自检」巡检项
★启发 3 · 筛≠拍「回退成本」→ 止损阈值升级为「回退成本判据」P20-3待执行
理解：「下游不可逆要看影响乘数」——判断该不该加人把关，更准的口径是看「回退成本」。
修改计划：把止损阈值（P16-2）/ 可证伪验收三问（P6-1 失败回退）统一成「回退成本判据」——判断自动化动作该不该加人把关，看「回退成本 = 时间 × 金钱 × 信任损失」是否超阈值，超了加人兜底；与 P15-3 Agent 治理审计合并。
验收标准：止损阈值/可证伪验收三问出现「回退成本判据」（时间×金钱×信任损失）统一规则
